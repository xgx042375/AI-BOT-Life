# 角色卡（人格）说明

## 文件位置与切换

- 角色卡目录：`<安装根>\qq-bot\data\personas\`
- **切换角色：私聊 `/人设 卡名`**（热切换，无需重启；每人可自选，bot 全局形象跟随主人选择）
- 模板：`_template.json`（复制改名即可用）
- 切换时：模式状态重置、记忆按切换时间分界（旧卡记忆不注入）、昵称/头像强制应用

## 字段说明（TavernAI chara_card_v2 标准 + 扩展）

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 角色名 |
| `nickname` | 可选 | QQ 昵称跟随 |
| `description` | ✅ | 人设：身份、性格、与用户的关系 |
| `personality` | 建议 | 性格标签，逗号分隔 |
| `scenario` | 可选 | 场景设定（参考；实际场景由管理员通过场景系统动态切换） |
| `universe` | 建议 | 世界观键（自定义，如 `your-world`）——关联 `data/scenes.json` 场景库与 `world` 包。**注意别用第三方作品名**：你自备的角色与素材要不要用某个世界观，由你自己判断合规性 |
| `first_mes` | 可选 | 开场白（当前版本不自动发送） |
| `mes_example` | 可选 | 示例对话，展示说话风格 |
| `system_prompt` | 可选 | 留空 = 自动组装；填写 = 整体覆盖系统提示 |
| `post_history_instructions` | 可选 | 历史后置指令 |
| `response_rules` | 强烈建议 | 说话方式/关系质感（**不是拦截规则**：接不接话、怎么接由 agent 自决） |
| `think_flow` | 建议 | **卡级思考流程**（agent 自决范式）：①眼前这件事 ②落到我身上的感觉（先在心里过；想说就说成一句台词；按好感度/在哪儿/在做什么决定走向，无标准答案）③我这一刻想怎么接（选当下最像我的，不背公式）；无卡级时用通用自决档 |
| `style_sample` | 建议 | 口吻要素清单（自称/称呼/语气/标志句）——参考不抄 |
| `alt_persona` | 可选 | 破防/摸鱼/恶堕形态（mode=1 演出；`keyword` 触发词） |
| `owner_mode` | 可选 | 主人体系卡（仅对你本人的主人身份生效）：启用主人专属机制（亲密层推进、群聊表现等，细节由卡声明） |
| `no_arrogance` | 可选 | 跳过全局高傲注入 |
| `sticker_dir` | 可选 | 表情包素材目录 |
| `avatar` | 可选 | 头像素材（mode0/1） |
| `mode_trigger` | 可选 | `self` 自决 / `keyword` 关键词切换 |

## 组装逻辑（plugins/persona/__init__.py）

```
build_system_prompt(card, mem_text, mode)
  = 人设基底（description/personality/lore/response_rules/style_sample 口吻要素）
  + 【记忆】mem_text（事实库/关系状态/对话摘要）
  + 口语化基准 / 常用语库
后由 brain 追加四层感知：①【场景】②【当前场景·层级】③【你们的关系 X/100】④ think_flow 思考流程
```

## 提醒

- `response_rules` / `think_flow` 是**表达层提示**：控制"像不像这个角色"，不控制"能不能说"——接不接话、说什么、怎么演全过程由 agent 自决；机器只守协议事故（思考推演列表/情绪标签泄漏/格式残句 → 反馈重试）与配置边界（状态机仅管理员、独处场景免打扰）
- 角色卡之间可随时切换，记忆库按用户分开存，不互相污染
- 动作口径：`（动作）`只装主动肢体行为；反应/描写（脸红/心跳/温度/瑟缩）留在心里，想说就说成一句台词
