# 表情包素材规范（STICKER_PACKS）

> 2026-09-12 T13 通用化重写配套文档（用户裁决 D10）。
> 表情素材是**预制素材**，**不走 ComfyUI 管线生成**（`E:\comfyui\lib\emotes` 是奥丁时代的外部产物，
> 不接入项目、不做兼容）。

## 1. 目录规范（唯一一套）

```
qq-bot/data/stickers/<卡键>/<情绪>/*.{png,jpg,jpeg,webp,gif}   ← 人设专属（可选）
qq-bot/data/stickers/_common/<情绪>/*.{png,jpg,jpeg,webp,gif}  ← 通用库（跨卡可用）
```

- `<情绪>` ∈ **9 类之一，目录名必须逐字匹配**（与 `qq-bot/plugins/emotion/__init__.py` 的
  `CLASSIFY_PROMPT` 候选集同名）：

  `开心` `难过` `生气` `惊讶` `害怕` `厌恶` `平静` `委屈` `害羞`

- **不限制尺寸/格式**（png/jpg/jpeg/webp/gif 均可），**不要求文件命名规则**——
  文件归属哪个情绪只看它所在的目录名。
- `<卡键>` = 人设卡文件名（不含 `.json`），如 `amiya` / `kaltsit` / `_aoding_`。
- 目录名不在 9 类内的目录**整段不被读取**（例如旧三维 `善-正常-开心/`）——静默跳过，不报错。

## 2. 双库与取图顺序

| # | 来源 | 说明 |
|---|---|---|
| 1 | 人设专属 · 该情绪 | 卡字段 `sticker_dir` 指向的库根下 `<情绪>/` |
| 2 | **通用库 · 该情绪** | `data/stickers/_common/<情绪>/` |
| 3 | 人设专属 · 任意情绪 | 该人设库里有图就行 |
| 4 | **通用库 · 任意情绪** | 通用库里有图就行 |
| 5 | — | 都没有 → **不发图**（静默，不影响文字/语音） |

"尽量不与最近一张同图"行为保留（候选多于一张时优先选与上次不同的那张）。

## 3. 卡字段 `sticker_dir`

- 可选。指向该卡的**人设专属库根**（内含 `<情绪>/` 子目录）。为空/不存在 → 直接走通用库。
- 旧三维目录（`{人格}-{状态}-{情绪}`，如 `E:\comfyui\lib\emotes`）**不再被读取**：
  取不到就静默不发图，绝不抛错。三维体系与 24 情绪词表随 T13 整体退役。
- `.env` 的 `STICKER_DIFF_DIR` 仍保留为启动配置项，但**不再进入取图链**（仅为 debug 面板回显）。

## 4. 情绪来源（`[STICKER]` 标记协议不变）

- 发不发**由 agent 自决**：回复末尾追加 `[STICKER]`（不带词）或 `[STICKER:情绪]`（带词）。
- 带词 → 情绪即该词（先经 `plugins/emotion` 的 `EMOTION_ALIASES` 归一；不在 9 类内则交 judge 选）。
- 不带词 → 回落本条自标【基调】（`brain._tone_now`）作为情绪线索。
- 两者都无 → judge 从 9 类里选一个（一次本地 LLM 判定；`sticker_enabled()` 关闭时不发生）。
- 总开关 `/表情 开|关`（落 `data/sticker_mode.json`）；异常回复（`[大脑离线]`/报错类）不配图。

## 5. 素材准备（人工，不走管线）

直接把图片丢进对应情绪目录即可：

```powershell
# 通用库：所有卡都能用
Copy-Item 我的表情\*.jpg E:\robot\qq-bot\data\stickers\_common\开心\

# 人设专属：只给某张卡用（并在卡里写 sticker_dir）
Copy-Item 阿米娅表情\*.png E:\robot\qq-bot\data\stickers\amiya\害羞\
```

> 本机 `data/stickers/` 下另有 13 个**历史目录**（2026-09-08 前一版代码用过，现行代码不读取）：
> `开心/ 生气/ 委屈/ 害羞/ 加油/ 亲亲/ 撒娇/ 晚安/ 温馨/ 无语/ 得意/ 嘲讽/ 震惊/`。
> 它们不在规范位置上（情绪目录须位于 `_common/` 或 `<卡键>/` 之下）。启用方式见
> `data/stickers/_common/README.md` 末节。
