## 〇、总览

一句话：**NapCat QQ → NoneBot2 → plugins/brain 顺序主链 → core（llm/packs/special/reply）→
QQ / GAL web 双出口**；后台 agent 层（lifesim 心跳 / 主动 / 复盘）持续喂养主链；数据面收敛
`data/`（运行时）与 `qq-bot/data/`（人设卡与配置）。发行走"封闭核心 + 开放 SDK"三包
（`build/build_release.ps1`），私有内容另出本地分发件（`release/local-content/`）。

## 一、launcher（启动器）

- **职责**：WebView2 壳 + PS 宿主；承载 generic 中性主页、GAL 客户端、设置/日志/状态三管理页；
  皮肤包机制（launcher-skin-v1）；bot 启停与消息通道；在线换人设 HTTP 通道。
- **关键文件**：
  - `launcher/Launcher.ps1`：主宿主（皮肤 manifest 加载、`data/launcher.json` 的 skin 键、
    state.json 载荷组装、postMessage 命令通道、虚拟主机映射、状态页 `Get-LifeLog` 尾 100 条
    时间线（ScrollViewer 滚动翻阅）、卡表回退）。
  - `launcher/web/index.html + home.css + app.js`：generic 主页（正在/心情/卡网格/详情弹层/
    管理行）；`gal.html + gal.js + gal.css`：GAL 客户端（WS 单连接、sprite 差分帧、
    逐行 `POST /gal/tts` 语音、回想轮次渲染、`window.GAL_RENDERER` 钩子）。
  - `launcher/web/skins/generic/`：tracked 默认皮肤（零图片素材）；`skins/arknights/`：
    gitignored 本地皮肤包（方舟样板，经 `tools/export_content_packs.py` 可出本地分发件）。
  - `launcher/QQAI-Launcher.exe`：ps2exe 产物（与 Launcher.ps1 双处同步）。
- **对外接口指针**：`docs/皮肤包接口规范-v1.md` §2 manifest / §3 state.json 数据契约 /
  §4 PS↔web 命令通道 / §5 虚拟主机 / §6 data/cards.json 卡片数据源 / §7 GAL 皮肤钩子 / §8 方舟样板。

## 三、plugins（bot 插件面）

| 插件 | 职责（要点） |
|---|---|
| `plugins/brain` | 顺序主链：`handle` 入口（纯图/声文/纯文感知分流、群聊门控、连发聚合、命令分流）→ 感知装配（`memory.build_context` 语义召回、挂落回放、悬念/周复盘）→ **stage1 内容**（思考自决，【认真】开思维链）→ 并行任务：约定自决 + **owner facts 预解析**（主人私聊全角括号触发）→ **stage2 润色**（`core/reply.generate`：基调目标/长度自决/替号动作/漂移回退）→ 硬边界兜底 → 发送+消费（TTS/表情/约定台账/基调→语音与差分同源）。`PERSONA_ALIAS` 别名表；`_SCENES_FILE=qq-bot/data/scenes.json` |
| `plugins/memory` | 记忆库 `data/memory.db`（messages/facts/events/emotions/summaries/open_threads/fact_corrections）+ 语义召回（`memory/embeddings.py` 向量服务 :11435，qwen3-embedding；`EMBED_ENABLED` 可关）；`build_context` 组装 L1-L4 上下文；群梗库 |
| `plugins/voice` | TTS：GPT-SoVITS 整合包子进程池（`tools/` gitignored）、内置 `VOICES` 表 + 包 voice.json `setdefault` 合并、9 类情绪 `EMO_PARAMS`（语气参数）、`tts_wav` 串行锁；无音色卡不触发 |
| `plugins/webgal` | GAL web 出口：WS 单连接（token 鉴权，`data/webgal_token.txt`）、帧协议（auth/msg/mode/ping ↔ auth_ok/reply_start/seg/sprite/state/reply_end/err）、`/gal/content.json`（`core.packs.content_index`）、`/gal/tts`、合成轮 CaptureBot、`data/gal_history.jsonl` 回想落盘（Phase 2b）、gal 门停用 QQ 通道 |
| `plugins/fiction` | 长文写作（写小说/续写/改第N章/大纲），meta+大纲+分章持久化 `data/fiction/` |
| `plugins/emotion` | 情绪引擎：LLM 9 类分类（失败规则兜底）→ VTube Studio Live2D 参数注入（未启动静默降级）→ 落库 emotions |
| `plugins/correction` | 对话矫正：LLM 判定矫正意图 → `data/corrections.json`（每用户 ≤10 条，仅主人）→ `build_context` 注入"对方纠正过的说话方式" |
| `plugins/sticker` | 表情包联动：本地差分目录优先、LLM 评估回复情绪即发（无 API、无限次） |
| `plugins/persona` | 人设卡（chara_card_v2）解析与系统提示组装：`/人设` 列表（本地卡+包卡合并）、切换、`colloquial_style.txt`/`common_phrases.txt` 口语化约束、`persona.list_persona_entries` 来源标记 |
| `plugins/debug` | 运维与后台循环宿主：日志/状态命令、引擎 watchdog、`start_background_loops_async` 注册 **主动循环**（45min 级：候选主人白名单、生活分享/停息事实/约定到期，感知后 agent 自决说不说、发送后才落账防复读）与 **复盘循环**（每小时：日复盘补扫、周盘点、checkpoints prune、`_sweep_stale`） |
| `plugins/livesource` | 直播弹幕源：`register_handler(fn)` 经 `agent/registry` 注册 ToolCard（B2 接线），弹幕归一化后交注册钩子自决消费 |
| `plugins/qq_avatar` | NapCat 扩展换头像（善良/恶堕头像槽，brain 模式切换自动联动） |
| `plugins/search` | Bing 联网搜索（网页+图片直链，无 key，失败返回空） |

## 四、agent 层（`qq-bot/agent/`）

- **registry.py**：`ToolCard` 能力总线（name/description/fn/failure/needs_llm），`@register`
  装饰器自注册 + 命令式注册（同名查重），铁律#1 的受控执行环境入口；livesource 等插件锚点。
  接口指针：PLUGIN_SDK §5（ToolCard 行）。
- **graph.py**：agent 主循环（`_perceive → _decide → _act → _reflect`）+ langgraph 装配 +
  `agent_checkpoints.db` 落盘与 `prune_checkpoints`（keep 30 天）；主动/复盘等非消息链路复用。
- **lifesim.py**：心跳（自决节奏 wake_min ±10% 抖动、启动恢复 tick）——doing 生成
  `max_tokens=120` → `data/life_state.json`（doing/scene/mood/约定痕迹）+
  `data/life_log.jsonl`（上限 400 条，状态页时间线滚动翻阅约 8 天）；夜间睡眠保护、
  久别 >2h「这段时间的事」注入、切卡时 `data/life_states/` 整组归档、日记
  `life_diary.jsonl`、对话微更新 `micro_update_from_conversation` / `apply_interaction`。
- **llm.py / tools.py / state.py / guardrails.py**：agent 侧 client 委托 core.llm（purpose
  "agent"）、工具集、AgentState、护栏。
