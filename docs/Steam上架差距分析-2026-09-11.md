# Steam 上架差距分析：从本地项目到可上架产品（2026-09-11）

> 前置口径：Steam Direct 费 **$100/应用**（一次性，$1,000 调整后毛收入后返还）；分成 30%
> （$1M 万/$5,000 万以上降 25/20%）；无月费、无托管费（depot 由 Valve 托管）；AI 内容须过
> Content Survey 申报（live-generated 须描述护栏，责任在开发者）。
> 评级：🔴 硬门槛（不做上不了架）/ 🟡 体验门槛（做了才像商品）/ ⚪ 生态不成熟点（工坊/创作者经济）。

## 一、最低销售费用全貌

| 项目 | 金额/口径 |
|---|---|
| Steam Direct 费 | **$100/应用**，一次性；累计 $1,000 调整后毛收入（AGR，含内购）后由 Steam 返还 |
| 分成 | 30%（AGR 超 $10M → 25%，超 $5,000 万 → 20%）；仅商店销售与 Steam 内购 |
| 月费/托管 | 无——depot 分发与带宽由 Valve 承担 |
| 退款 | 用户 2 小时/14 天无条件退款由 Steam 处理；退款率影响商店曝光 |
| 税务 | 合作伙伴税务访谈（W-8BEN）；中国开发者中美条约下美国来源收入预提约 10% |
| AI 内容 | Content Survey 强制申报；live-generated 须描述防违法/防侵权护栏（2025 起申报范围收窄至游戏内/营销内容） |

## 二、当前项目 → 可上架产品的差距

### 🔴 硬门槛（不做就上不了架/活不了）

1. **路径可移植化**：硬编码 `E:\robot` 于 py 32 处、PS 33 处（五之七审计清单）。Steam 安装目录
   由用户与库位置决定（可能含中文/空格），必须全部改为相对安装根推导（core/paths.py 已是雏形）。
2. **QQ/NapCat 依赖剥离**：NapCat 需 QQ 登录且非可分发组件——Steam build 以 **GAL 页为主界面**
   （本地引擎 + gal 页即完整体验，本就无需 QQ），QQ 通道整体移出发行版（私仓保留）。
3. **模型随包分发**：主模型 GGUF（GB 级）+ embedding 0.6B 必须随 depot 下载（Steam depot 支持
   大文件，免自建下载器）；**模型许可条款需确认允许随商业应用再分发**（Gemma/Qwen 各有条款）。
4. **一键即玩**：Steam"开始"按钮 → 引擎挂载 → 健康等待 → 就绪进 GAL 页（start.ps1 流程收编进
   exe）；退出全清保留。
5. **AI 披露落地**：Content Survey 申报 live-generated；商店页描述护栏（scale_baseline/回应规则
   体系 + 输出约束）；护栏文本进框架。
6. **防呆与自检**：venv/杀软误报/端口占用/中文路径——安装器或免安装绿色包 + `-Mode status`
   自检扩容为"安装体检"。
7. **法务四件**：EULA、隐私政策（"数据全本地"是卖点，如实写）、AI 披露文本、Valve 合作伙伴
   注册（税务访谈/银行/身份）；另需模型许可与 IP 政策法务口径。

### 🟡 体验门槛（做了才像商品）

8. 首启引导 GUI 化：模型下载进度 → 首任人设选择 → 皮肤选择 → 就绪（现 GETTING_STARTED 的交互化）。
9. 卸载清理：卸载时用户数据（data/）保留或删除的二选一确认。
10. 崩溃兜底：引擎/venv/端口异常的可见化（已有 boot_err/-Mode status 雏形）→ 汇总为"体检报告"。
11. Steam 成就/集换卡：可选，无也行。

### ⚪ 生态不成熟点（工坊/创作者经济想做之前必须补）

1. **Workshop(IGC) 集成**：ISteamUGC 上传/下载/版本化——Python/PS 栈最重单点工程；
   过渡方案=工坊页做发现 + 插件管理页手动导入（已具备）。
2. **pack 跨版本治理**：CORE_API_VERSION 有了，但无迁移/废弃公告机制；工坊更新即覆盖，用户侧
   无回滚路径。
3. **创作者审核体系**：OC（原创角色）规范、DMCA 下架流程、举报通道、质量分级——全部从零。
4. **语音包创作门槛极高**（GPT-SoVITS 训练链路）：短期语音包不进工坊，生态内可产出者寥寥。
5. **数据回流缺失**：包的安装量/活跃度无统计（opt-in 埋点未做），创作者无法感知受欢迎度。
6. **多语言**：文档与 UI 全中文——全球发行至少需英/日语化核心 UI 与创作者文档。
7. **Live2D/沙盒等接口仍是立桩**：预留未实现，工坊作者会要（排期在优化清单 #23 系）。
8. **R18 层的工坊外治理**：站外点对点分发已是决定，但缺"非官方分发目录"的白/黑名单自治。

## 三、最小可上架组合（MVP-S 建议）

SFW build = **gal 页主界面 + 本地引擎（模型入 depot）+ 插件管理 + 状态页**：
1. 路径可移植化（硬门槛 1）；
2. QQ/voice/Live2D 全部剥离出发行版；
3. 模型入 depot + 首启引导；
4. AI 披露 + EULA/隐私 + SFW 护栏文本；
5. 插件管理页（已具备）承担"生态入口"，Workshop 集成延后到生态验证期。
